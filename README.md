# WebDavMusicPlayer

Android  WebDAV 音乐播放器。

> 本软件已在 **小米 14 手机** 和 **车机设备**（横屏 1280×720 车机模拟器实机）上完成全量测试验证，功能运行稳定。

## 功能说明

- **WebDAV 播放**：一键扫描 WebDAV 全部音频，边听边缓存（LRU 缓存可开关、上限可调）
- **歌词同步**：逐行高亮 + 逐字卡拉OK效果，支持增强型 LRC；本地 .lrc 优先，在线歌词多接口兜底（lrclib / api.lrc.cx / QQ音乐 / 酷狗 / lyrics.ovh / 网易云）
- **专辑封面**：本地缓存优先，网易云 → QQ音乐 → 酷狗 → iTunes 多接口级联获取
- **智能预加载**：当前曲目封面/歌词加载完成后，自动预加载下一曲封面、歌词及音频首段（1MB），切歌零等待
- **横竖屏双布局**：横屏列表+播放面板（车机风格），竖屏全屏播放页+播放队列弹层
- **8 套主题配色**：星云紫 / 森林绿 / 网易红 / 深海蓝 / 落日橙 / 珍珠白 / 透明毛玻璃 / 雅致黑，支持深色模式
- **播放控制**：顺序 / 随机 / 单曲循环 / 列表循环，收藏爱心，进度条拖动，时间显示
- **续播记忆**：重启恢复上次曲目与进度，自动续播行为可在设置中配置
- **车机适配**：分辨率自适应、刘海屏沉浸、方向盘媒体按键、系统媒体通知
- **安全**：HTTPS 默认系统 CA 校验（可选信任自签证书）、密码加密存储、防明文流量
